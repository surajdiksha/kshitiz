# Kshitiz

A lightweight, responsive personal introduction page for **Kshitiz**, published at [kshitiz.dikshayogi.co.in](https://kshitiz.dikshayogi.co.in/).

## Site

- Single-file static site in `index.html`; no build step or runtime dependencies.
- GitHub Pages can serve the repository root from the `main` branch.
- `CNAME` is retained for `kshitiz.dikshayogi.co.in`.
- The page links to the supplied Instagram and Facebook profiles.

The supplied social profile pages were not accessible to the site authoring session, so the page uses no unverified biographical details.
