# Kshitiz Shankar

A lightweight, responsive introduction page for Kshitiz Shankar, published at [kshitiz.dikshayogi.co.in](https://kshitiz.dikshayogi.co.in/).

## Site

- Static site with no build step or runtime dependencies.
- The page uses Kshitiz's name, his Instagram bio line and one Instagram post caption, each attributed to its source.
- The hero portrait is stored in `assets/kshitiz.jpg`.
- Links to the supplied Instagram and Facebook profiles.
- GitHub Pages serves the repository root from the `main` branch; `CNAME` is retained for `kshitiz.dikshayogi.co.in`.

Additional friend-visible personal details were left out of the public introduction.
